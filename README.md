# مخالفات حي الهرم — ملء النماذج بالصوت

تطبيق بيملى نماذج إدارة التنظيم بحي الهرم بالصوت، ويطلّعها PDF جاهز للطباعة:
- محضر مخالفة أعمال
- قرار إيقاف أعمال مخالفة
- قرار تصحيح / إزالة أعمال مخالفة

**مفيش ذكاء اصطناعي ولا سيرفر.** فهم الكلام شغال على الموبايل نفسه بالكلمات المفتاحية (`www/js/parser.js`).
والكود واحد للنسختين: **موقع ويب (PWA)** و**تطبيق أندرويد (APK)**.

---

## 1) أسهل طريقة: GitHub (ببلاش) — موقع + APK أوتوماتيك

1. اعمل حساب على github.com، واعمل Repository جديد (Private أو Public).
2. ارفع كل محتويات الفولدر ده عليه (من غير `node_modules`).
3. في الـ Repo: **Settings → Pages → Source: GitHub Actions**.
4. أي push على `main` هيعمل لوحده:
   - **الموقع:** يتنشر على `https://USERNAME.github.io/REPO/`. افتحه من Chrome على الموبايل، ومن ⋮ اختار **إضافة إلى الشاشة الرئيسية**.
   - **الـ APK:** من تبويب **Actions**، افتح آخر run وانزل لتحت لـ **Artifacts** ونزّل `mokhalafat-haram-apk`. فكه، وانقل الـ `.apk` للموبايل وسطّبه (هيطلب السماح بتثبيت التطبيقات من مصادر غير معروفة).
   - لو عملت tag زي `v1.0.0`، الـ APK هيتحط كمان في **Releases**.

> ملاحظة: الـ Repo لو Private، GitHub Pages محتاجة خطة مدفوعة. الحل: خلّي الـ Repo عام (مفيش فيه أي بيانات، البيانات على الموبايل بس)، أو استخدم Netlify (تحت).

## 2) الموقع بس من غير GitHub: Netlify Drop
افتح https://app.netlify.com/drop واسحب فولدر **`www`** عليها، فيديك رابط https شغال على طول.

## 3) بناء الـ APK على جهازك (Android Studio)
محتاج: Node 20+، وJDK 21، وAndroid Studio.
```bash
npm install
npm run android:sync     # ينسخ www جوه مشروع الأندرويد
npm run android:open     # يفتح Android Studio → Run ▶ أو Build → Build APK
```
فولدر `android/` موجود وجاهز، والـ manifest فيه صلاحيات المايك.
لو مسحته: `npm run android:add && npm run android:icons`.

## الفرق بين الويب والأندرويد

| | الويب (Chrome) | تطبيق الأندرويد |
|---|---|---|
| المايك | التعرف على الصوت بتاع Chrome (محتاج نت) | التعرف على الصوت بتاع أندرويد (ممكن من غير نت لو حزمة العربي متنزلة) |
| حفظ الـ PDF | في التنزيلات | `Documents/مخالفات` |
| إرسال واتساب | زرار "إرسال" (مشاركة) | زرار "إرسال" (مشاركة) |
| الطباعة | من الملف | "فتح للطباعة" ← قارئ PDF ← طباعة |
| البيانات | على الموبايل (IndexedDB) | على الموبايل |

**النسخة الاحتياطية:** البيانات على الجهاز بس. من الإعدادات ← تصدير، وابعت الملف لنفسك كل فترة. ومن "استيراد" ترجّعها على أي موبايل.

### المايك من غير نت على أندرويد
الإعدادات ← Google ← خدمات الصوت (أو تطبيق Google ← الإعدادات ← الصوت) ← التعرف على الكلام بلا إنترنت ← نزّل **العربية (مصر)**.

## إزاي تتكلم
قول اسم الخانة وبعدها القيمة، مثلاً:
> قطعة ٤٥ ل، شارع التقسيم، المالك عبد الله صلاح الدين، الرقم القومي ٢٩٧٠٩…، عنوانه ٢٥ شارع الهرم حي الهرم محافظة الجيزة، ترخيص رقم ٥٨ لسنة ٢٠٢٥، عدم تنفيذ الدروم وزيادة البروزات، من الدور الأرضي إلى الدور الرابع، المسطح ١٠٠ متر

- الأرقام تتقال عادي ("تلتمية أربعة وعشرين" بتبقى ٣٢٤)، وكذلك التواريخ ("خمسة حداشر"، "النهارده"، "٢ نوفمبر") والساعة ("عشرة ونص الصبح").
- **خانة خانة:** وضع التطبيق فيه يسألك خانة خانة، والمايك يفتح لوحده ويروح للي بعدها.
- أي خانة ناقصة بتطلع في شاشة "كمّل الناقص"، واللي مش موجود يتكتب فيه ( / ).

## هيكل المشروع (لو هتعدّل)
```
www/
  index.html            الصفحة
  css/app.css           الشكل
  js/parser.js          فهم الكلام: الكلمات المفتاحية، الأرقام، التواريخ، الأدوار، المخالفات
  js/platform.js        المايك والتخزين والحفظ/المشاركة (ويب أو أندرويد)
  js/app.js             الشاشات، الحقول، صياغة الديباجة، رسم النماذج (إحداثيات كل خانة في L = {...})
  tpl/*.jpg             صور النماذج الفاضية
  fonts/ vendor/ icons/
  sw.js                 الكاش للعمل من غير نت — غيّر VERSION مع كل تحديث
test/parser.test.js     اختبارات فهم الكلام:  npm test
scripts/android-patch.cjs  صلاحيات الأندرويد
.github/workflows/build.yml  نشر الموقع + بناء الـ APK
```
- **كلمة جديدة يفهمها:** زوّدها في جدول `KW` في `parser.js`، وبعدين زوّد اختبار في `test/parser.test.js`.
- **نوع مخالفة جديد:** زوّده في `VIOL` في `app.js`، وفي `VIOL_RX` في `parser.js`.
- **مكان خانة على الورقة:** `L.report / L.stop / L.removal` في `app.js`. الإحداثيات على صورة 1066×1600.
- **بعد أي تعديل:** غيّر `VERSION` في `sw.js`، و`APP_VERSION` في `app.js`، وارفع.
